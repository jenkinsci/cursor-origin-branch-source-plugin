When checked, this credential may be used freely in pipeline steps such as withCredentials and withGit, exposing the raw access token to arbitrary shell commands.

When unchecked (the default), the credential is restricted: it can only be used by trusted Jenkins infrastructure (such as checkout scm) that scopes the token to the specific repository being accessed. Pipeline steps that would expose the token to user-defined code are refused.

Only enable this for credentials whose app installation has been intentionally granted access to all repositories that pipeline authors may target.
